# Limitations

- Copilot exposes selected model IDs and agent version but not immutable provider
  model build IDs. Evidence is therefore bounded to the disclosed selection
  boundary.
- Three repetitions characterize this protocol but do not establish broad
  statistical generality.
- The two Financial Services episodes do not represent every language, domain,
  codebase size, or delivery environment.
- Token counts are a consumption proxy, not a universal measure of engineering
  cost or environmental impact.
- Queue and throttle time can vary independently of productive execution time and
  is reported separately.
- With no timeout, a stalled run requires explicit cancellation; cancelled runs
  are retained and score zero.
- Monetary comparisons are unavailable until a dated, sourced rate card is
  frozen.
- The public repository can enforce artifact and workspace boundaries, but the
  operator must still ensure fresh conversations and correct permissions in the
  execution client.
- No measured results exist yet.
