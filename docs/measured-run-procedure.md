# Measured-run procedure

1. Complete both authoring sessions and validate their evidence contracts.
2. Independently approve both constitution/spec/plan/checklist/tasks chains and
   produce content-bound manifests.
3. Record all four freeze approvals and commit every frozen input.
4. Generate a ready freeze record from a clean worktree.
5. Create fresh implementation workspaces in the pre-registered order.
6. Launch the pinned model with high reasoning effort and the standard-coding
   permission profile. Do not impose a timeout or tool-call cap.
7. Capture terminal status, timestamps, productive time, queue/throttle time,
   tool calls, uncached input, cached input, output, and reasoning tokens.
8. Preserve the committed candidate source bundle/diff, transcript reference,
   and sealed evaluator output under the canonical run directory.
9. Import all 12 cells exactly once. Keep failed and cancelled cells.
10. Build the report only from the complete homogeneous version/spec matrix.
11. Publish per-episode claims and use the weaker episode for overall status.
12. Rebuild the single-file dashboard from the validated report.

Do not rerun only unfavorable cells, replace failed cells, edit evidence after
import, or mix benchmark/spec versions.
